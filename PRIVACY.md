# Privacy Policy — FreePad

**FreePad** is a free and open-source desktop software designed and maintained by zioti (*Fait par zioti*).

### Data Collection
FreePad respects your privacy:
- **No telemetry or personal data collection**: FreePad does not collect, store, or transmit any personally identifiable information (PII) to remote servers.
- **Audio processing is 100% local**: All audio playback, soundboard mixing, microphone injection, and instant replay clipping occur entirely on your local machine.
- **Auto-Update**: FreePad queries public GitHub Releases (`https://api.github.com/repos/ZIOTI/FreePad/releases`) solely to verify if a newer version is available. No user data is sent during update checks.

### Contact
If you have any questions regarding this privacy policy, you can open an issue on the official GitHub repository:
https://github.com/ZIOTI/FreePad
